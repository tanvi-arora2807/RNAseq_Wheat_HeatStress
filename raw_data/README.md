# RNA-seq Wheat Heat Stress Pipeline

This project demonstrates a beginner RNA-seq preprocessing and alignment workflow for wheat heat stress data using Linux command-line tools.

## Tools Used
- FastQC
- fastp
- HISAT2
- SAMtools

## Workflow
1. Quality control using FastQC
2. Read trimming using fastp
3. Reference indexing using HISAT2
4. Sequence alignment
5. SAM to BAM conversion
6. BAM sorting and indexing
7. Alignment statistics generation

## Files Generated
- fastqc reports
- trimmed FASTQ
- aligned SAM/BAM
- sorted BAM
- BAM index
- alignment statistics

## Skills Demonstrated
- Linux command line
- RNA-seq preprocessing
- Read alignment
- Bioinformatics workflow building
- File format handling (FASTQ/SAM/BAM)
